# Exporting timesheets to CSV

> Sample help article, invented for a Pulsar template. Tallyhop is a fictional product.

You can export any timesheet range to a CSV file for payroll or your accounting software.

1. Open Reports > Timesheets.
2. Choose the date range and, optionally, filter by person or project.
3. Click Export and choose CSV.

The file lists one row per time entry, with the person, project, task, date, start and end time, duration in hours, and whether the entry is billable.

Entries still running (timers not yet stopped) are not exported. Stop the timer first, then export again.
